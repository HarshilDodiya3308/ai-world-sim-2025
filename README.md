# AI World Simulation Engine

A complete Java Swing application featuring autonomous NPCs in a simulated world with explainable AI decision-making. This project demonstrates advanced AI concepts including personality-driven behavior, memory systems, and transparent decision reasoning.

## 🎯 Features

### Core Simulation
- **200x200 World Grid**: Expandable simulated environment with multiple terrain types
- **8 Autonomous NPCs**: Each with unique roles, personalities, and decision-making processes
- **7 Interactive Locations**: Forest, Village, Market, Mountain, Lake, Danger Zone, Safe Haven
- **Real-time Simulation**: Adjustable speed (10ms to 2000ms per step)

### AI Decision Engine
- **Explainable AI**: Every NPC decision includes reasoning explanation
- **Personality System**: 6 personality types affecting decision weights
  - Aggressive: Prefers attack and confrontation
  - Defensive: Prefers retreat and protection
  - Curious: Prefers exploration and discovery
  - Greedy: Prefers resource collection and trading
  - Helpful: Prefers assisting other NPCs
  - Balanced: Neutral on all dimensions

### NPC Capabilities
- **Dynamic State Management**: IDLE, MOVING, ACTING, RESTING, TRADING, EXPLORING, HELPING, DANGER
- **12 Distinct Actions**: MOVE, EXPLORE, ATTACK, RETREAT, REST, EAT, TRADE, COLLECT_RESOURCE, HELP, HEAL, PATROL, WAIT
- **Vital Statistics**: Health, Energy, Hunger, Money tracking
- **Memory System**: NPCs remember discoveries, dangers, successes, and failures
- **Relationship Tracking**: NPCs maintain relationships with each other

### Advanced Features
- **Decision History**: Track last 50 decisions per NPC with confidence scores
- **Memory Log**: Keep last 100 memories per NPC with importance weighting
- **World Events**: Random events affecting locations and NPCs
- **Resource Management**: Dynamic resource levels that deplete and regenerate
- **Danger Zones**: Environmental hazards that affect NPC behavior
- **Database Persistence**: SQLite integration for saving simulations

## 📊 Decision Engine Algorithm

The DecisionEngine evaluates each possible action using a multi-factor scoring system:

1. **Base Score**: 50 points (neutral)
2. **Health Factor**: Critical/Low health bonuses for healing/retreat
3. **Energy Factor**: Low energy penalties for strenuous actions
4. **Hunger Factor**: High hunger bonuses for eating/trading
5. **Environment Factor**: Danger/resource level adjustments
6. **Interaction Factor**: Bonuses for trading/helping based on nearby NPCs
7. **Personality Modifier**: Multiplier (0.5-1.5) based on personality type
8. **Memory Factor**: Bonuses based on past experiences

**Final Score = (Base + Factors) × Personality Modifier + Memory Bonus**

The NPC chooses the action with the highest final score.

- Visual representation of the 200x200 world
- Locations shown as colored squares (color intensity = danger level)
- NPCs shown as circles (color gradient = health status)

- **RESET**: Clear all NPC histories and restart

- List of all NPCs with current vitals

- Shows reasoning behind each decision

### 5. **Event Log Panel** (Right - Tab 3)
- Real-time log of all simulation events
- Timestamped entries
- Scrollable with auto-scroll to latest
- Useful for debugging and analysis

### 6. **Statistics Panel** (Right - Tab 4)
- World-wide statistics
- Population count and alive NPCs
- Simulation step count
- Average NPC health and energy
- NPC state distribution
- Most common actions being taken
- Total money in circulation

## 🚀 Getting Started

### Prerequisites
- Java 17 or higher
- Maven 3.6+
- SQLite JDBC (included in pom.xml)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/HarshilDodiya3308/ai-world-sim-2025.git
   cd ai-world-sim-2025
   ```

2. **Build the project**
   ```bash
   mvn clean package
   ```

3. **Run the application**
   ```bash
   mvn exec:java -Dexec.mainClass="com.aiworldsimulation.Main"
   ```

   OR

   ```bash
   java -jar target/ai-world-simulation-1.0.0.jar
   ```

### Quick Start

1. Launch the application
2. Click **START** to begin the simulation
3. Watch NPCs move, make decisions, and interact
4. Click on an NPC in the world to inspect its decision-making
5. Check the **Decision Inspector** tab to see reasoning
6. Adjust simulation speed with the speed dropdown
7. Use **PAUSE** to freeze and inspect, or **STEP** for manual progression

## 📁 Project Structure

### Model Classes (com.aiworldsimulation.model)
- **NPC.java**: Autonomous agent with state, inventory, memories, decisions
- **Location.java**: World locations with resources and danger levels
- **NPCRole.java**: Role enum (Guard, Trader, Explorer, Medic, Farmer, Scout)
- **Memory.java**: NPC memory events (Discovery, Danger, Success, Failure, etc.)
- **Decision.java**: Decision records with action scores and reasoning
- **WorldEvent.java**: Global events affecting the world state

### AI Engine (com.aiworldsimulation.ai)
- **DecisionEngine.java**: Core decision-making algorithm
- **Personality.java**: Personality traits affecting decision weights
- **WorldState.java**: Current world state for decision context

### Simulation (com.aiworldsimulation.simulation)
- **SimulationWorld.java**: World manager with locations and NPCs
- **ActionExecutor.java**: Executes NPC actions and updates world state
- **SimulationManager.java**: Lifecycle management (start, pause, step, stop)

### UI (com.aiworldsimulation.ui)
- **MainWindow.java**: Main application window
- **WorldSimulationPanel.java**: Visual world rendering
- **NPCListPanel.java**: NPC list and statistics
- **DecisionInspectorPanel.java**: Decision analysis display
- **EventLogPanel.java**: Event log display
- **StatisticsPanel.java**: World statistics
- **ControlPanel.java**: Simulation controls
- **SettingsPanel.java**: Settings dialog

### Database (com.aiworldsimulation.database)
- **DatabaseManager.java**: Database initialization and connection management
- **NPCDao.java**: NPC persistence operations
- **LocationDao.java**: Location persistence operations
- **MemoryDao.java**: Memory persistence operations
- **DecisionDao.java**: Decision persistence operations

### Utilities & Tests
- **IdGenerator.java**: Unique ID generation
- **ValidationUtil.java**: Input validation
- **Exception classes**: Custom exceptions
- **Test suite**: JUnit tests for core functionality

## 📈 Extending the Project

### Add New NPC Actions
1. Add to `NPC.NPCAction` enum
2. Implement in `ActionExecutor.executeAction()`
3. Add scoring logic in `DecisionEngine.evaluateAction()`

### Add New Personality Traits
1. Extend `Personality.PersonalityType` enum
2. Initialize in `Personality.initializeTraits()`
3. Add influence calculation in `Personality.getInfluenceForAction()`

### Add World Events
1. Create event in simulation loop
2. Add to `WorldState.activeEvents`
3. Modify NPC behavior based on events

## 🐛 Troubleshooting

**Issue**: Application won't start
- Ensure Java 17+ is installed: `java -version`
- Check Maven is installed: `mvn -version`
- Try: `mvn clean install` before running

**Issue**: No NPCs visible
- Check the World Simulation Panel (left side)
- Ensure simulation is running (START button)
- Click on circle representations to select

**Issue**: Database errors
- Delete `ai_world_simulation.db` file
- Application will recreate it on next run
